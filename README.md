# 💖 Sweetgram

![Sweetgram](logo.svg)

**Sweetgram** — форк Telegram с фирменным розовым стилем и набором авторских возможностей.

## ✨ Возможности

- 🎨 Розовая тема оформления: акценты, заголовки, счётчики, уведомления и иконки микрофона и камеры в звонках.
- 💬 Нежно-розовый фон чата по умолчанию.
- 🔔 Фирменный звук уведомлений и розовый сплеш при запуске приложения.
- 📢 Закреплённый канал [@SweetGramOfficial](https://t.me/SweetGramOfficial) в списке диалогов.
- 🤝 Кнопка поддержки в меню чата.
